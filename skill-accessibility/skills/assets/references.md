# Accessibility References & Testing Resources

Curated specifications, tool documentation, and testing resources for the 12 accessibility disciplines.

## Specifications

- WCAG 2.2 (full standard): https://www.w3.org/TR/WCAG22/
- How to Meet WCAG (quick reference): https://www.w3.org/WAI/WCAG22/quickref/
- ARIA Authoring Practices Guide (APG patterns): https://www.w3.org/WAI/ARIA/apg/patterns/
- WAI-ARIA 1.2 (roles/states/properties): https://www.w3.org/TR/wai-aria-1.2/
- ARIA in HTML (native semantics): https://www.w3.org/TR/html-aria/
- WCAG 2.2 What's New: https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/
- EN 301 549 (European procurement): https://www.etsi.org/deliver/etsi_en/301500_301599/301549/
- Section 508 (US federal): https://www.section508.gov
- Making Audio & Video Media Accessible: https://www.w3.org/WAI/media/av/
- Cognitive Accessibility Guidance (COGA): https://www.w3.org/WAI/WCAG2/wcag2ext-req/
