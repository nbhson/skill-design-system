# Typography References & Inspiration

Curated specifications, tool documentation, and learning resources for the 12 typography disciplines.

## Specifications

- CSS Fonts Module Level 4 (font-display, variations): https://www.w3.org/TR/css-fonts-4/
- @font-face unicode-range: https://developer.mozilla.org/en-US/docs/Web/CSS/@font-face/unicode-range
- font-variant-numeric: https://developer.mozilla.org/en-US/docs/Web/CSS/font-variant-numeric
- font-optical-sizing / variable fonts guide: https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_fonts/Variable_fonts_guide
- clamp() (fluid type): https://developer.mozilla.org/en-US/docs/Web/CSS/clamp
- size-adjust (fallback metric matching): https://developer.mozilla.org/en-US/docs/Web/CSS/@font-face/size-adjust
- OpenType feature tags registry: https://learn.microsoft.com/en-us/typography/opentype/spec/featuretags
- WCAG 1.4.12 Text Spacing: https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html
