# Color Theory References & Inspiration

Curated specifications, tool documentation, and learning resources for the 12 color disciplines.

## Specifications

- CSS Color Module Level 4 (oklch, oklab, color-mix): https://www.w3.org/TR/css-color-4/
- CSS Color Module Level 5 (relative colors): https://www.w3.org/TR/css-color-5/
- MDN oklch() reference: https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/oklch
- MDN color-mix(): https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/color-mix
- color-gamut media query (P3 enhancement): https://developer.mozilla.org/en-US/docs/Web/CSS/@media/color-gamut
- WCAG 1.4.3 Contrast (Minimum): https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- WCAG 1.4.11 Non-text Contrast: https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html
- APCA (contrast model): https://git.apcacontrast.com/documentation/APCAeasyIntro
- W3C WAI — Use of Color (1.4.1): https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html
